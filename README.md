# BAD TIME · 像素 MV

基于仓库里的 `music.mp3` 制作的高规格像素 MV（Hi-bit / Neo-Retro Pixel Action FX）。
保留原版战斗 UI 与点阵质感，叠加现代演出：3D 运镜、色差、残影、黑白反相冲击帧、辉光、故障撕裂、VHS 倒带，以及一段第一人称体素 3D。
所有画面都严格对齐音乐的 16 分音符网格。

叙事是屠杀线（Genocide）：主角是冷酷清空地底世界的玩家。整场战斗里它的攻击一次也打不中；「仁慈」被删除，「行动」「物品」被击碎；
最后 Sans 耗尽力气睡着，它顶着战斗框一路推到「战斗」按钮上，直接斩断按钮本身——用打破第四面墙的方式赢下战斗。结尾没有胜利的欢呼，只剩一个问题，和音乐结束后的几秒寂静。

## 观看

- **成片**：用 `tools/render.cjs` 在本地导出（见下文「导出视频」），1920×1080 60fps，已混入音效。
- **实时播放器**：用 Chrome / Edge 打开 `index.html`（本地双击即可），或在仓库根目录执行 `npx http-server` 后访问。
  - `空格` / `Z`：播放 / 暂停；`←` `→`：快退 / 快进 2 秒（按住 Shift 为 1 小节）；`D`：显示时间 / 小节 / 段落；点击底部进度条跳转。
  - URL 参数：`?t=64` 从 64 秒开始；`?lat=0.03` 调整画面与声音的延迟校准；`?cut=tiktok` 播放 TikTok 竖屏版（见下文）。
- **TikTok 竖屏版**：`node tools/render.cjs --cut=tiktok --gpu --vcodec=h264_nvenc --workers=3` → `dist/mv_tiktok_1080x1920_60.mp4`。

## TikTok 竖屏版（`?cut=tiktok`）

1080×1920 60fps，约 71 秒：从第 44 小节「战斗」被选中、四连斩开始，一直到结尾的问题（静默尾声留 3.5 秒）。54–59 小节的新编舞和 68–70 小节的入睡过程两个版本共用（见下方段落表）；竖屏版只多了下面这些。

- **竖屏取景**：16:9 编排的镜头在竖屏里按 `TL.pcam` 放宽（默认 k = 0.62，并把画面略微上移，避开 App 底部的文案区）；HUD 攻击、竖井、疲惫段、尾声菜单文字这几处单独调了取景。第一人称体素段按同一个 k 换算纵向视场角，所以 2D → 3D 的无缝接手在竖屏里同样成立。
- **炮台不出画**：每门炮（以及巨龙的每个兽颅）都登记在 `TL.focus` 里；`H.framePortrait` 逐帧算出竖屏视野还差多少才能把所有在场的炮和红心装进来，提前一点、快速地拉开 / 平移过去，炮走后再慢慢收回，结果烘焙进 `TL.pcam`。不需要时画面和手调的一模一样；遇到镜头硬切（以及段落标记的 `TL.frameCuts`，如第 48、56 小节的重拍）不做提前量，保证推镜不会被提前拉开。
- **台词气泡**：竖屏里单独给一个镜头，把 Sans 和整个气泡框在一起，一直停到最后一个字「打？」落下，第 47 小节第二拍再硬切到他点燃的眼睛。
- **HUD 攻击看得清**：竖屏放不下整排 HUD，所以第 54 小节镜头偏向左侧拍名字 BOMEI，第 55 小节的 LV 与 HP 数字由外向内依次发射，镜头每一步只放宽到刚好能拍到下一个要发射的字母，边推近边保证它在画面里。
- **冷开场**（第 44 小节）：第一帧直接切到 Sans 的笑脸（故障撕裂）慢推，四个光标出发时拉开全景；四连斩每一刀都加了反相冲击帧。
- **音效**：只在游戏原声之上加了很轻的一层 —— HUD 字母和瞬移的呼啸、进入第 56 小节 / 俯冲进心脏 / 斩断按钮前的三次反向镲、第 55 小节撕裂处一声故障音（`src/synth.js` 生成，播放器和导出共用）；不加任何低频闷响。16:9 完整版只用游戏原声。导出时 `--cut` 默认开启前视峰值限制器（5 ms 前视、80 ms 释放），只在有瞬态冲出去时才压，不会把整首歌一起调小。

## 技术实现

- **无状态时间轴**（`src/engine.js`）：每个画面元素都是时间 t 的纯函数（关键帧轨道 + 事件），任意一帧都能单独渲染，所以实时播放、拖动、逐帧导出、倒带都是同一套代码。
- **世界**：960×540 视窗（原版 640×480 布局 1:1 居中，左右留给炮台和运镜），Sans / 炮台 2 倍像素，心与骨头 1 倍，和原作一样的混合分辨率。
- **骨头**：参数化生成（任意长度、粗细、角度、白 / 蓝），蓝骨沿边缘冒出细小的冷焰火星。
- **后期**（`src/post.js`，WebGL）：像素世界是一张平面，由真正的 3D 相机拍摄（俯仰 / 偏航 / 翻滚 / 推拉，远处还有一层视差虚空网格）；双层辉光、径向色差、黑白反相冲击帧、故障切片、甩镜运动模糊、VHS、点阵网格、暗角。
- **第一人称 3D**（`src/voxel.js`）：低分辨率帧缓冲里的定向长方体（骨头 = 骨干 + 关节块）、光照 + 雾、公告板 Sans / 炮台，自发光写在 alpha 通道供辉光使用。
- **碰撞校验**（`tools/check.cjs`）：以 240 Hz 采样整首，保证白骨和光炮从未碰到心、蓝骨只在心静止时穿过（剧本里唯一一次“被击中”单独标注）；第一人称段落同样检查光炮和白骨与镜头的距离。HP 只在画面上真的被打中时才会变化（砸到 HP 条、第 36 小节的死亡、第 62 小节正面的光炮和第 63 小节墙里的骨头）。
- **音效**：原版音效按时间表触发（骨刺、炮台蓄力 / 开火、砸墙、斩击、心碎、菜单、打字音），播放器里用 WebAudio 预排程，导出时由 `tools/render.cjs` 直接混进音乐（并在结尾补齐静音）。

## 导出视频

需要 Node.js 18+、ffmpeg（N 卡 GPU 编码需带 `h264_nvenc`，`ffmpeg -encoders | findstr nvenc` / `grep nvenc` 可查）和 Playwright：

```bash
npm i -g playwright
npx playwright install chromium
# Windows 下如果 require('playwright') 找不到，先设 NODE_PATH 为 `npm root -g` 的输出
```

**一步导出**（浏览器用 GPU 渲染 WebGL，NVENC 编码，自动混音）：

```bash
node tools/render.cjs --gpu --vcodec=h264_nvenc --workers=2 --out=dist/mv_1080p60.mp4
```

**先出帧、再自己用 ffmpeg 编码**（方便换编码参数或中断续跑）：

```bash
node tools/render.cjs --gpu --frames=dist/frames      # 写 dist/frames/00000.jpg… 和 dist/mix.wav
ffmpeg -framerate 60 -i dist/frames/%05d.jpg -i dist/mix.wav -map 0:v -map 1:a \
  -c:v h264_nvenc -preset p5 -rc vbr -cq 19 -b:v 0 -pix_fmt yuv420p \
  -c:a aac -b:a 256k -shortest -movflags +faststart dist/mv_1080p60.mp4
```

常用参数：`--cut=tiktok`（竖屏版，默认 1080×1920、自带时间范围）、`--limit` / `--limit=0`（混音限制器，剪辑版默认开）、`--fps=60 --w=1920 --h=1080`、`--t0 / --t1` 只导出一段、`--workers` 并行浏览器数、`--channel=chrome` 改用本机 Chrome、`--headful`（部分驱动下 headless 拿不到 GPU 时用）、`--vcodec=hevc_nvenc | h264_amf | h264_qsv | libx264`、`--vopts="…"` 自定义编码参数；环境变量 `FFMPEG` 指定 ffmpeg 路径。
不加 `--gpu` 时用 SwiftShader（纯 CPU），能跑但慢很多。

## 重新生成素材 / 校验

```bash
pip install numpy scipy librosa pillow          # 另需 ffmpeg
python3 tools/analyze_music.py                   # music.mp3 -> src/analysis.js
git clone --depth 1 https://github.com/Jcw87/c2-sans-fight ../c2-sans-fight
python3 tools/import_assets.py ../c2-sans-fight  # -> src/assets.js
python3 tools/make_font.py                       # 扫描台词用字 -> src/glyphs.js
node tools/check.cjs                             # 编舞碰撞校验（整段 0–160 s）
node tools/check.cjs 88 160 --cut=tiktok         # 校验 TikTok 版
node tools/frames.cjs out 16.06 64.2 144.06      # 渲染指定时刻的静帧（加 --cut=tiktok 出竖屏静帧）
```
